material. A card-level license label alone does not prove that the mirror holds
all rights to the lecture audio, speaker likeness, and transcripts. Therefore
public release of derived weights is **blocked** until the original rights
holder, exact license text, copyright attribution, and redistribution rights
have been independently verified and retained with the release record.

This repository stores only code and provenance. It does not redistribute the
source audio, transcriptions, translations, or per-sample predictions.
